# YardRover Component Library

Welcome to the YardRover component library! This Storybook contains interactive documentation for all the Vue 3 + Quasar components in the YardRover application.

## About YardRover

YardRover is an autonomous yard utility machine controlled via a web application. The system consists of:

- **ESP32 Device**: C++ firmware with MAVLink integration
- **Web App**: Vue 3 + Quasar 2 + TypeScript frontend
- **API Client**: TypeScript library for device communication

## Component Categories

### Common Components
Basic reusable components used throughout the application:
- **AppLogo**: Application logo with various sizes and colors
- **ConnectionIndicator**: Real-time connection status display
- **LoadingSpinner**: Loading indicators with customizable appearance

### Connection Components
Components for device discovery and connection management:
- **ConnectionDialog**: Manual device connection dialog
- **ConnectionStatus**: Detailed connection status display
- **DeviceCard**: Individual device information cards
- **SavedDevicesList**: Manage and display saved devices

### Dashboard Widgets
Interactive dashboard widgets for monitoring and control:
- **ActivityWidget**: Real-time activity timeline
- **MachineStatusWidget**: Current machine status display
- **QuickActionsWidget**: Quick control actions
- **SystemHealthWidget**: System health metrics
- **TelemetryWidget**: Live telemetry charts

### Layout Components
Layout and navigation components:
- **NavItem**: Navigation menu items

## Design System

The application uses a nature-inspired color palette:

- **Primary**: #2C5F2D (Forest Green)
- **Secondary**: #87CEEB (Sky Blue) 
- **Accent**: #FF6B35 (Sunset Orange)
- **Background**: #F5F5DC (Soft Beige)

## Getting Started

1. Browse the components in the sidebar
2. Use the **Controls** panel to interact with component props
3. Check the **Docs** tab for component documentation
4. View different component states using the predefined stories

## Mock Data

All components use realistic mock data to demonstrate functionality without requiring a live device connection.
